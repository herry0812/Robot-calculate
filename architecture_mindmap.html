四、分支详细规划表

分支名 模块名称 类型 功能描述 依赖关系
main 主分支 核心 稳定发布版，所有模块合并后的最终版本 无
feat/main-performance 整机性能计算 核心 牵引力、速度、爬坡、续航、稳定性等综合计算；调度调用其他模块 齿轮、电机、电池
feat/gear-design 齿轮传动选型 模块 直/斜齿轮、行星轮、蜗轮蜗杆设计与强度校核 共享参数库
feat/cam-design 凸轮设计计算 模块 盘形/移动凸轮轮廓曲线设计、压力角校核、动力学分析 共享参数库
feat/motor-selection 电机选型 模块 伺服/步进/直流电机功率扭矩匹配、转速范围、过载能力 整机性能、共享参数库
feat/bearing-shaft 轴承与轴 模块 轴承类型选择、寿命校核 L10、轴径计算、临界转速 齿轮传动、共享参数库
feat/belt-chain 链条/皮带传动 模块 同步带/链传动设计、张紧力计算、传动效率 电机选型、共享参数库
feat/battery 电池容量计算 模块 基于功率消耗计算电池容量、续航里程、充电方案 整机性能、电机选型
feat/cost-estimation 成本评估 模块 BOM 成本、加工成本、批量折扣、敏感性分析 所有机械模块
feat/shared-params 共享参数库 数据层 材料属性、标准齿轮表、轴承型号、电机规格等公共数据 无（基础层）
feat/integration 集成联调 核心 模块间接口对接、联动测试、数据传递验证 所有模块
feature/ui Web 交互界面 辅助 参数输入表单、结果可视化图表、方案对比 集成联调
