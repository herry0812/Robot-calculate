# 四向穿梭车整机设计计算工具

纯前端、零后端的工程初算工具。输入参数即实时出结果，用于四向穿梭车（Four-Way Shuttle）整机的行走驱动、轮压、顶升、电池续航、稳定性、结构与尺寸链、换向节拍初算，并给出可直接用于选型讨论的校核清单。

> **本工具为工程初算辅助，最终选型须由工程师结合电机/减速机/轮子样本与实际工况实测复核；结果不替代强度校核、型式试验与安全评估。**

---

## 1. 运行方式

- **方式一（推荐）**：双击 `index.html`，用 Chrome / Edge / Firefox 打开即可，无需安装、无需构建、无后端。
- **方式二**：放到任意静态服务器（Nginx、GitHub Pages、对象存储）作为单页托管。
- 唯一外部依赖是 Chart.js 4（jsdelivr CDN）。首次打开需联网一次，之后走浏览器缓存；完全离线时页面仍可计算、导出、打印，仅图表区显示"图表库未加载"占位提示。
- `localStorage` 在 `file://` 协议下可用（Chrome/Edge/Firefox 默认允许）。若企业策略禁用了 `file://` 的存储，改用方式二即可。

### 界面构成

| 区域 | 内容 |
|---|---|
| 顶部栏 | 方案名、保存、另存为、方案管理、导入、导出 JSON / CSV、打印 PDF、重置、载入示例、语言（中/英/日） |
| 左侧参数区 | ①基本与载荷 ②外形与轮系 ③行走驱动 X ④行走驱动 Y ⑤顶升机构 ⑥电池与续航 ⑦工况与尺寸链 ⑧高级系数（默认折叠） |
| 右侧结果区 | 12 张关键指标卡片 → 计算明细表（项目/符号/公式/代入值/结果/单位）→ 校核清单 → 3 张曲线图 |
| 方案抽屉 | 已保存方案列表：载入 / 复制 / 重命名 / 删除 |

交互要点：

- 输入即算，防抖 250 ms，无需点"计算"。
- 越界或非数值输入框标红，该值不参与计算（沿用上一次有效值），并在结果栏提示。
- 每个参数左侧 `?` 悬停显示公式与取值建议。
- 功率在 W / kW、力在 N / kN 之间自动换算，也可在结果区顶部锁定单位。
- "自动求解减速比"：开启时 `i` 为输出（只读）；关闭后 `i` 为输入，速度按 `v = π·D·n_m / (60i)` 反解并回填全链。
- "顶升质量"自动模式 = 载重 + 托盘 + 0.5×车重；切手动后可自填。
- 参数变更后标题栏显示"未保存"，关闭页面会提示；草稿自动存在本地，刷新可恢复。
- 宽度 ≥1280 px 左右分栏，<1280 px 上下堆叠。

## 3. 计算公式

设 `M = m_load + m_pallet + m_self`，`g = 9.81 m/s²`。全部系数取自参数区，代码中不硬编码。

### 3.1 行走阻力与功率（X / Y 独立）

```
F_f  = M·g·f·cosα            滚动阻力
F_g  = M·g·sinα              坡度阻力
F_a  = M·a                   加速阻力
ΣF   = F_f + F_g + F_a
P_v  = (F_f + F_g)·v / η     匀速功率
P_pk = ΣF·v / η              加速峰值功率
P_m  = P_pk·K_s              电机总功率需求
P_m1 = P_m / k               单机功率
n_w  = 60·v / (π·D/1000)     轮转速
i    = n_m / n_w             减速比（自动模式）
T_w  = ΣF·(D/2000)           轮上扭矩
T_m  = T_w / (i·η)           电机扭矩
附着 = μ·M·g·(k/4) ≥ ΣF      附着力校核
```

自动模式关闭时：`v = π·D·n_m/(60·i)`，其余公式不变。

> 附着力校核按需求书原式 `μ·M·g·(k/4)` 判定，明细表并行给出 `μ·M·g·k/n_w` 供参考——前者按整车重的 1/4 估算驱动轮可传递的附着力，属于偏乐观的简化，余量小于 10% 时会给出黄色警告。

### 3.2 轮压（赫兹线接触）

```
N     = M·g·K_d / n_w                    单轮法向载荷
E*    = E / (1 − ν²)                     等效弹性模量（钢轨视为刚体）
a_h   = √( 4·N·R / (π·b·E*) )            接触半宽，R = D/2000，b、R 取 m
A     = 2·a_h·b                          接触面积
p_avg = N / A                            平均轮压
p_max = 4·p_avg / π                      峰值轮压（圆柱-平面线接触）
N_max = N·(1 + 2e/B)                     偏心工况最大单轮压
```

轮压校核比较的是 `p_max` 与许用轮压，偏安全。

### 3.3 顶升机构

```
F_lift = m_lift·g·K_imp
v_lift = (h/1000) / t_lift
P_lift = F_lift·v_lift / η_lift

液压：d_req = √(4·F_lift/(π·p·10⁶)) → 圆整到标准缸径序列
      p_act = 4·F_lift/(π·d²)          实际工作压力
      Q_hyd = A_cyl·v_lift·60000       所需流量 L/min
丝杠 / 电动推杆：T = F_lift·P_lead / (2π·η_lift)
凸轮：等效导程取行程 h，T = F_lift·h / (2π·η_lift)
```

### 3.4 电池与续航

```
t_travel = s_c / v
E_c      = P_v·t_travel + n_lift·P_lift·t_lift      （Wh）
E_day    = E_c·N_day / 1000                          （kWh）
Q_req    = E_day·1000 / (U·DOD·η_b)                  （Ah）
E_use    = U·Q·DOD·η_b                              单次可用能量（Wh）
N_ok     = E_use / E_c                              可循环次数
续航 h   = N_ok·(t_travel + n_lift·t_lift) / 3600
N_chg    = ⌈ E_day·1000 / (E_use·η_ch) ⌉            每日充电次数
t_chg    = Q·DOD / I_ch                             单次充电时长
```

"能耗计算口径"切到"加减速曲线积分"时，`E_c` 中的行走部分改为按梯形/三角形速度曲线逐段积分 `∫F(t)·v(t)/η dt`，更接近真实启停工况。

### 3.5 稳定性与制动

```
H_cg,act = ((m_load + m_pallet)·h_cg + m_self·h_cg_self) / M
a_crit,X = g·(轴距/2)/H_cg,act        （支距口径"按行驶方向"时用 A）
a_crit,Y = g·(轮距/2)/H_cg,act
K_st     = a_crit / a  ≥ 1.5
s_b      = v² / (2·a_b)
F_b      = M·a_b
T_b      = F_b·(D/2000)/(i·η)        轮上制动扭矩折算到电机
```

X、Y 分别计算稳定系数，卡片显示两者中的较小值。若把支距口径切到"严格按 B/2"，两个方向都用轮距计算（对应需求书原文写法）。

### 3.6 结构与尺寸链

```
q     = M·g·K_d / (n_b·L)            单根主梁均布线载（N/mm）
M_max = q·L² / 8                     简支梁最大弯矩（N·mm）
I     = (B·H³ − b·h³)/12             方管截面惯性矩（mm⁴）
W_x   = 2I / H
σ     = M_max / W_x  ≤  σ_s / K_struct
δ     = 5·q·L⁴ / (384·E·I)  ≤  L/n
```

尺寸链：

```
H_deck = H + t_fork
c_v    = h_layer − (H_deck + h_cargo + h_lift + Δh)     垂直间隙
c_side = (w_slot − w_fork) / 2                          侧向间隙（货叉）
c_cart = (w_slot − W) / 2                               侧向间隙（车身）
c_min  = min(c_v, c_side, c_cart)                       负值即干涉
```

### 3.7 换向（四向特有）

```
离地间隙 = Δh ≥ clr_wheel（默认 3 mm）
行程校核 = h_lift ≥ Δh + clr_lift
换向时间 t_sw = t_down + t_delay
完整周期      = 2·t_lift + t_delay
节拍          = 3600 / t_sw
```

`t_sw` 沿用需求书定义（下降 + 延时），所以数值偏乐观；明细表同时给出"含上升的完整周期"，实际节拍应以完整周期或行走时间为准。

## 4. 系数取值建议

### 轮材质库（切换材质会自动联动 `f` 与许用轮压）

| 材质 | E (MPa) | ν | f | 许用轮压 (MPa) | 适用 |
|---|---|---|---|---|---|
| 聚氨酯 95A | 30 | 0.49 | 0.020 | 5 | 常规轻中型，静音、护轨 |
| 尼龙 | 3000 | 0.40 | 0.015 | 25 | 中重载，耐磨 |
| 钢 | 206000 | 0.30 | 0.005 | 600 | 重载，需淬火导轨 |
| 橡胶 | 10 | 0.49 | 0.030 | 2 | 轻载、防滑，不推荐重载 |

> 许用轮压是经验值，实际应以轮子厂商样本的"额定动载 / 接触面积"为准；聚氨酯轮尤其受硬度与温度影响。切换材质后仍可在"高级系数"里手动改回。

### 其他系数

| 系数 | 建议范围 | 备注 |
|---|---|---|
| 滚动阻力 `f` | PU 0.015–0.03；尼龙 0.012–0.02；钢 0.003–0.008 | 轨道有粉尘、油污取上限 |
| 传动效率 `η` | 行星/斜齿 0.90–0.95；蜗轮蜗杆 0.60–0.80 | 含轴承与链传动损失 |

## 9. 已知简化与假设

1. **轮压用赫兹线接触**，钢轨视为刚体，未考虑轨道弹性与轮子永久变形；峰值轮压按 `4p_avg/π` 估算。
2. **主梁按简支梁均布载荷**，未做扭矩、剪切、焊缝与疲劳校核；截面按等壁厚方管。
3. **顶升功率按平均速度**计算，未计液压系统容积效率、溢流与热平衡；丝杠未做压杆稳定校核。
4. **电池能耗**默认按匀速近似（需求书口径），可切换为加减速曲线积分；未考虑温度、老化与辅助功耗（PLC、传感器、通信）。
5. **换向节拍**按"下降 + 延时"计算，偏乐观；实际受行走时间、定位精度与 PLC 节拍约束。
6. **稳定性**做静力临界加速度估算，未考虑轮子弹性、轨道不平顺、偏载动态转移与风载。
7. 每向轮数假设载荷均分（`n_w` 等分），未做四角不平或三点支撑的重新分配（偏心工况按线性放大近似）。
