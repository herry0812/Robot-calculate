# 齿形链传动设计工具（Silent Chain Designer）

纯前端、零后端的齿形链传动工程初算 + 参数化 3D 建模 + STEP 导出工具。双击 `index.html` 即可运行；计算、2D 齿廓、方案管理与计算书完全离线，3D 预览与 STEP 导出按需加载 OpenCascade（WebAssembly）。

> 本工具依据 **GB/T 10855-2016** 进行工程初算；渐开线模式不在该标准覆盖范围内。最终链轮齿形、公差与链条选型须以标准原文和供应商样本复核。

---

## 1. 文件与运行

```
.
├── index.html   # 单文件应用：UI + CONFIG + ChainCalc + CAD + Store
└── README.md    # 本文件
```

- **运行**：直接双击 `index.html`。
- **计算 / 2D / 方案 / 计算书**：不依赖网络，`file://` 可用。
- **3D / STEP**：需要网络加载 `opencascade.js@1.1.1`（wasm 约 **65.8 MB**，主源 unpkg，jsDelivr 对该 wasm 返回 403）与 `three@0.149.0`（约 600 KB）。首次加载显示下载进度；失败时给出可读原因与重试按钮。
- 若浏览器因安全策略禁止 `file://` 下的跨域模块导入，请在本目录启动本地服务后访问：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```

浏览器要求：Chrome / Edge / Firefox 近两年版本，支持 WebAssembly、ES Module、`localStorage`。

## 2. 标准依据（重要）

| 项目 | 内容 |
|---|---|
| 主标准 | **GB/T 10855-2016《齿形链和链轮》**（现行，代替 GB/T 10855-2003） |
| 适用范围 | 短节距**外接触式**齿形链及链轮；**链轮齿廓不包括渐开线型** |
| 补充参考 | **ASME B29.2M**（GB/T 10855-2016 起草参考来源） |
| 渐开线模式 | 额外参考 **JB/T 11803-2014** 的齿形与根切约束思路；**不在 GB/T 10855-2016 覆盖范围内，结果仅供设计参考** |
| 未采用 | **不引用 ISO 1275**（该标准针对双节距滚子链，与齿形链无关） |

版本与免责声明在页面顶部品牌区、8 号指标卡与底部固定栏中同步展示。

### 关于链条型号命名

`08B / 12B / 16B` 属于滚子链型号体系（ISO 606），**不是** GB/T 10855-2016 的齿形链型号。本工具因此：

- 节距系列按 `CONFIG.pitchSeries` 维护（6.35 / 9.525 / 12.7 / 15.875 / 19.05 / 25.4 / 31.75 / 38.1 / 44.45 / 50.8 mm），下拉仅用于快速填 `p`；
- 内置示例方案按**节距**命名（轻载 p12.7 / 中载 p19.05 / 重载 p25.4），避免与滚子链混淆；
- 算例中的“12B 级”仅作为 Q 的输入示例，**不参与型号推断**；12B 实际节距 19.05 mm，与 p=12.7 mm 不一致，自检报告中已明确标注。

## 3. 功能

1. **参数选型计算**：链条拉力、链轮几何、根切校核、磨损寿命估算、链速/包角/齿数辅助校核。
2. **传动组件模型**：链轮按 z 参数化生成齿形，链条按标准配件参数生成示意链节，2D 齿廓与 3D 预览。
3. **导出与持久化**：一键导出 STEP（B-Rep 实体）、STL（预览网格）、计算书打印/PDF、方案 localStorage 保存/加载/重命名/删除/JSON 导入导出。

左侧参数分为 6 组（基本 / 链条 / 链轮 / 材料 / 工况 / 齿形高级），每项带单位、范围与公式 tooltip；右侧为指标卡、校核清单、明细表与模型预览。

## 4. 计算模型

全部计算集中在 `const ChainCalc = {...}`（纯函数，不依赖 DOM），系数全部来自 `const CONFIG = {...}`，页内「更多 → 系数与来源溯源表」可逐条查看来源与状态。

### 4.1 链轮几何

| 量 | 公式 | 说明 |
|---|---|---|
| 分度圆直径 | `d = p / sin(180°/z)` | GB/T 10855-2016 基本公式，标准可得 |
| 直齿廓齿顶圆 | `da = d + 2·ka·p` | `ka` 默认 0.30，工程占位，待标准齿形表核对 |
| 直齿廓齿根圆 | `df = d − 2·kf·p` | `kf` 默认 0.33，与“p=12.7 时 z_min≈17”的工程经验锚定 |
| 渐开线齿顶圆 | `da = d + 2m(ha*+x)` | `m = p/π`，`ha*=1.0` |
| 渐开线齿根圆 | `df = d − 2m(hf*−x)` | `hf*=1.25` |
| 跨柱测量距 | 偶数 z：`d + dr`；奇数 z：`d·cos(π/2z) + dr` | `dr = 0.55p` 为量柱直径**占位**，公差表未填入 |

### 4.2 根切判定（几何约束，与拉力无关）

**标准直齿廓**：齿槽在齿根圆处是否闭合。

```
w(ρf) = 2π·ρf/z − [ p/2 + 2(r − ρf)·tan(αc/2) ] ≥ 0
ρf = r − kf·p，r = p / (2 sin(π/z))
```

- 对 `z = 6…80` 数值搜索，取第一个满足 `w(ρf) ≥ 0` 且齿顶未变尖（`t_a > 0`）的齿数作为 `z_min`，**不写死 17**；
- 输出齿根槽宽余量 `w(ρf)/p`，供判断是否临界；
- 关闭「自动求解 z_min」时，按用户手输 `z_min` 只做通过/不通过判定（直齿廓与渐开线均生效）。

**渐开线模式**（JB/T 11803 思路，仅参考）：

```
z_min = ⌊ 2(ha* − x) / sin²α ⌋
x_min = ha* − z·sin²α / 2
```

- α=20°、x=0 → `z_min = 17`（严格几何限 17.1，按惯例取整）；
- 开启「自动求解唯一变位」时，取 `x = max(0, ha* − z1·sin²α/2)`，此时 z=16 也可通过（自检中已覆盖该行为）；
- 渐开线理论中 `z_min` 由 `ha*、α、x` 决定，齿距 p 仅通过模数影响绝对尺寸；**未编造节距修正系数**，`CONFIG.geom` 预留了扩展位置。

不通过时结果卡标红，并给出“增大 z / 正变位 / 改用直齿廓”的建议。

### 4.3 链条拉力与强度

```
v = π·d1·n1 / 60000          [m/s]
Ft = 1000·P / v              [N]
Fc = q·v²                    [N]
F_work = KA·Ft               [N]（工程简化：松紧边统一放大）
S = Q / F_work
Q_req = [S]·F_work
```

- `[S]` 默认 10，可调 7~12；`Q` 由用户按样本填写（默认 40 kN 为**示例值**）；
- 结果输出实际安全系数、所需 Q 与当前型号裕度。

### 4.4 磨损寿命（显式包含链轮齿数影响）

```
T_h = C_w · ε_lim · p · z1 · b · k_m · k_l / (K_w · F_work · v)
K_w = KA · f_粉尘 · f_温度
```

| 项 | 含义 | 量纲 / 取值 |
|---|---|---|
| `ε_lim` | 许用磨损伸长率 | 默认 3%，精密传动 1.5% |
| `p`、`b` | 节距、链宽 | mm |
| `z1` | 小链轮齿数（正相关：啮合齿数↑、单齿比压↓、多边形效应↓） | — |
| `k_m` | 材料配对磨损系数 | `√(km_轮 · √(km_板·km_销))`，45 钢调质=1.0 |
| `k_l` | 润滑修正 | 充分 1.0 / 滴油 0.7 / 不良 0.4 |
| `K_w` | 工况磨损系数 | KA × 粉尘(1.35) × 高温(1.20) |
| `C_w` | **标定常数** | 默认 `1.0×10⁶ h·W/mm²`，`state=calib` |

> **量纲说明**：题目给定的经验式分子为 mm²、分母为 W，量纲不闭合。实现时引入 `C_w` 使结果单位为 h，并在 README 中给出反标定公式：
>
> `C_w = T_ref · K_w · F_ref · v_ref / (ε_lim · p_ref · z1_ref · b_ref · k_m · k_l)`
>
> 默认值使参考工况（p12.7 / z19 / b20 / 5 kW / KA1.3）落在 1.97×10⁴ h 量级。**未标定时绝对寿命不可用于承诺**，UI 中该常数标注为「需标定」。

模型保留 z1 正相关与材料系数；自检中断言“z1 19→25 寿命上升”“功率翻倍寿命下降”。结果同时给出折合工作年数。

### 4.5 辅助校核

- 链速 `v ≤ v_lim`（充分 25 / 滴油 15 / 不良 8 m/s，工程推荐）；
- 包角 `α_w = 180° − 57.3°(d2−d1)/a`，建议 ≥120°；
- 中心距推荐 `a_rec = max(30p, (d1+d2)/2 + 2p)`，范围判断 30p~80p；
- 齿数推荐 `z_rec = max(z_min+2, 17)`，同时给出几何最小与寿命推荐两个值。

## 6. 3D 建模与 STEP 导出

- 使用 **opencascade.js 1.1.1（OpenCascade WebAssembly）** 在浏览器内做 **B-Rep 参数化建模**，STEP 由 `STEPControl_Writer` 写出，**不是三角网格改扩展名**。
- 链轮齿廓与 2D 预览同源（`ChainCalc.profileEdges`）：
  - 直齿廓：**直线齿侧 + 真圆弧齿顶/齿根**（`BRepBuilderAPI_MakeEdge` + `gp_Circ`）；
  - 渐开线：渐开线齿侧按段离散为直线边 + 圆弧，属于几何近似；
  - 轴孔与键槽合并为一个内环，与齿廓一次拉伸成型（不做布尔运算，速度快、STEP 更干净）。
- 轮毂：简化环形凸台，作为独立实体与轮盘贴合，不做布尔融合；轮毂形式（无/单侧/双侧）仅影响 3D。
- 链条：按“标准配件”处理，生成 5 节共 10 片链板 + 6 根销轴的**示意装配**（合计 16 个链节零件），沿节距阵列并与分度圆相切，置于轴向爆炸视图（Z 向偏移）。UI 常显「链条为示意装配，选型以标准配件参数为准」。
- 导出对象为多实体装配（默认 18 个实体：1 链轮 + 1 轮毂 + 16 链节零件），可按 `STEP` 下载；另有 `STL`（预览网格，非 STEP）。
- 导出时先将 18 个实体合并为一个 `TopoDS_Compound`、一次 `Transfer` 写出（相对路径），避免逐实体传输在大装配上偶发写空文件；STEP 回读为 1 个复合根，内含 18 个 `MANIFOLD_SOLID_BREP`。
- 建模完成后自动做**包围盒校验**：模型外径 vs 计算 `da`、厚度 vs 齿宽，偏差 >1% 给出警告。
- 内核加载/建模/导出失败均给出可读错误与重试入口，不静默失败。

一次典型导出（p12.7 / z19，默认参数）：建模约 0.8 s，网格化约 0.3 s，STEP 约 4 s，文件约 3.0 MB（3,008 KB）；STL 约 139 KB（2,774 三角面）。

## 7. 数据持久化

`localStorage` 键：`silentchain.schemes`

```json
{
  "schemaVersion": 1,
  "items": [
    {
      "id": "sc_xxx",
      "name": "示例方案 · 轻载 p12.7",
      "createdAt": "2026-...",
      "updatedAt": "2026-...",
      "params": { "n1": 1000, "p": 12.7, "z1": 19, "...": "..." },
      "summary": { "p": 12.7, "z1": 19, "z2": 38, "P": 5, "Fwork": 1609, "life": 19739, "undercut": true, "lifeOk": true }
    }
  ]
}
```

- 单方案 JSON：`{ schemaVersion, type: "silentchain-scheme", exportedAt, scheme }`
- 全部方案 JSON：`{ schemaVersion, type: "silentchain-all", exportedAt, items }`
- 导入时校验 `params` 必填数值（`p、z1、z2、n1、P`）与范围；同名方案弹窗询问「覆盖 / 另存为副本」。
- 参数变更未保存时，标题与顶部圆点显示「未保存」。
