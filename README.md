# OKS 机器人设计计算工具

纯前端、零后端的工程初算工具。输入参数即实时出结果，用于 **OKS 超轻型四向机器人** 的行走驱动、轮压与塑料货架、凸轮组（顶升 + 换向）、电池续航、稳定性、结构与尺寸链初算，并给出可直接用于选型讨论的校核清单。

> **本工具为工程初算辅助，最终选型须由工程师结合电机/减速机/凸轮/轮子样本、塑料货架承载试验与实测工况复核；结果不替代强度校核、型式试验与安全评估。**

## 1. 产品定义（本工具的计算口径）

| 项目 | 定义 |
|---|---|
| 机型 | OKS 四向机器人（超轻型） |
| 额定载重 | 最大 **50 kg** |
| 整车自重 | **< 50 kg** |
| 承载方式 | **潜伏式顶升**，无货叉；车体顶面即承载面，`H_deck = H` |
| 轮系 | 共 **8 轮**：X 向 4 轮 + Y 向 4 轮 |
| 凸轮组 | 每个角 **1 个 X 轮 + 1 个 Y 轮 + 1 个圆柱凸轮** = 1 组，共 4 组 |
| 顶升/换向 | **同一凸轮**完成顶升与换向，四个角度位置对应四种状态 |
| 货架 | 纤维增强塑料（立柱与搁板均为塑胶），每库位 4 根支柱、1 个箱子 |

### 四状态（凸轮角度）

| 凸轮角度 | 举升状态 | 行走方向 | 承载轮组 | 非承载轮 |
|---|---|---|---|---|
| 0° | 未举升 | X 向 | X 轮组 4 轮 | Y 轮组离地 Δh |
| 90° | 举升 | X 向 | X 轮组 4 轮 | Y 轮组离地 Δh |
| 180° | 未举升 | Y 向 | Y 轮组 4 轮 | X 轮组离地 Δh |
| 270° | 举升 | Y 向 | Y 轮组 4 轮 | X 轮组离地 Δh |

举升时顶板托起货架行走；未举升时车体可潜入货架下方。页面结果区会按当前参数实时输出该表。

## 2. 运行方式

- **方式一（推荐）**：双击 `index.html`，用 Chrome / Edge / Firefox 打开即可，无需安装、无需构建、无后端。
- **方式二**：放到任意静态服务器（Nginx、GitHub Pages、对象存储）作为单页托管。
- 唯一外部依赖是 Chart.js 4（jsdelivr CDN）。完全离线时页面仍可计算、导出、打印，仅图表区显示"图表库未加载"占位提示。
- `localStorage` 在 `file://` 协议下可用（Chrome/Edge/Firefox 默认允许）。若企业策略禁用了 `file://` 的存储，改用方式二即可。

### 界面构成

| 区域 | 内容 |
|---|---|
| 顶部栏 | 方案名、保存、另存为、方案管理、导入、导出 JSON / CSV、打印 PDF、重置、载入示例、语言（中/英/日） |
| 左侧参数区 | ①基本与载荷 ②外形与轮系 ③行走驱动 X ④行走驱动 Y ⑤凸轮组（顶升+换向） ⑥电池与续航 ⑦工况、塑料货架与尺寸链 ⑧高级系数（默认折叠） |
| 右侧结果区 | 12 张关键指标卡片 → 四状态切换表 → 计算明细表 → 校核清单 → 3 张曲线图 |
| 方案抽屉 | 已保存方案列表：载入 / 复制 / 重命名 / 删除 |

交互要点：

- 输入即算，防抖 250 ms，无需点"计算"。
- **非法输入不沿用旧值**：越界、空值或非数字会标红，并在输入框下方显示"原因 + 允许范围"；右侧结果区切换为错误面板，逐项列出「错在哪 / 允许范围 / 影响哪些计算 / 如何修正」，计算暂停（不展示历史结果），修正后自动恢复。
- 每个参数左侧 `?` 悬停显示公式与取值建议。
- 功率在 W / kW、力在 N / kN 之间自动换算，也可在结果区顶部锁定单位。
- "自动求解减速比"：开启时 `i` 为输出（只读）；关闭后 `i` 为输入，速度按 `v = π·D·n_m / (60i)` 反解并回填全链。
- "顶升质量"自动模式 = 载重 + 托盘（顶升整垛），不再叠加车重。
- 参数变更后标题栏显示"未保存"，关闭页面会提示；草稿自动存在本地，刷新可恢复。
- 以 1920×1080 为桌面基准：420 px 参数栏 + 自适应结果区，12 张指标卡按 6×2 排列，三张图表同排；1280–1599 px 指标卡按 4×3 排列，<1280 px 上下堆叠。页面最大宽度 1920 px，超宽屏居中。

## 4. 计算公式

设 `M = m_load + m_pallet + m_self`，`g = 9.81 m/s²`，每向 4 轮、共 4 组凸轮。全部系数取自参数区，代码中不硬编码。

### 4.1 行走阻力与功率（X / Y 独立）

```
F_f  = M·g·f·cosα            滚动阻力
F_g  = M·g·sinα              坡度阻力
F_a  = M·a                   加速阻力
ΣF   = F_f + F_g + F_a
P_v  = (F_f + F_g)·v / η     匀速功率
P_pk = ΣF·v / η              加速峰值功率
P_m  = P_pk·K_s              电机总功率需求
P_m1 = P_m / k               单机功率
n_w  = 60·v / (π·D/1000)     轮转速
i    = n_m / n_w             减速比（自动模式）
T_w  = ΣF·(D/2000)           轮上扭矩
T_m  = T_w / (i·η)           电机扭矩
附着 = μ·M·g·(k/4) ≥ ΣF      启动不打滑
s_b  = v² / (2·a_b)          制动距离
```

### 4.2 轮压、支柱与塑料搁板

```
N      = M·g·K_d / 4         单轮法向载荷（每向 4 轮承载）
E*     = E / (1 − ν²)        轮材等效弹性模量
a_h    = √(4·N·R / (π·b·E*)) 赫兹接触半宽，R = D/2000
A      = 2·a_h·b             接触面积
p_avg  = N / A ; p_max = 4·p_avg / π
p_lim  = min(p_allow, p_shelf)   轮压许用值（塑料搁板常是薄弱环节）
N_max  = N·(1 + 2·e_off / by)    偏心最大轮压
N_post = M·g·K_d / 4             每库位 4 根支柱分摊
σ_post = N_post / post_b²        塑料支柱压应力 ≤ p_shelf
N_post ≤ post_load               单柱许用载荷
```

### 4.3 凸轮组（顶升 + 换向）

```
F_lift = m_lift·g·K_imp          顶升力（自动 m_lift = 载重 + 托盘）
F_cam  = F_lift / 4              每组凸轮顶升力
v_lift = (h_lift/1000) / t_lift  顶升线速度
P_lift = F_lift·v_lift / η_cam   顶升功率
ω_cam  = 2π·n_cam / 60           凸轮角速度
T_cam  = F_cam·v_lift / (ω_cam·η_cam)   凸轮输出转矩（功率法）
α      = atan((h_lift / φ) / r_base)   压力角，φ 取弧度
t_index = (φ/360) / n_cam · 60   分度（换向）时间
t_state = max(t_lift, t_index) + t_delay   状态切换时间
节拍    = 3600 / t_state         次/h
```

> **运动学一致性提示**：`n_cam` 应按凸轮实际曲线与 `t_lift` 匹配，建议 `n_cam ≈ φ·60/(360·t_lift)`。若两者相差较大，`T_cam` 仍按功率法给出，仅作初筛，最终须按凸轮接触应力与曲线复核。

### 4.4 电池与续航

```
t_travel = s_c / v
E_c      = P_v·t_travel + n_lift·P_lift·t_lift   （Wh）
E_day    = E_c·N_day
Q_req    = E_day / (U·DOD·η_b)                   （Ah）
E_use    = Q·U·DOD·η_b
N_ok     = E_use / E_c ; 续航 h = N_ok·t_cycle/3600
N_chg    = ⌈E_day/(E_use·η_ch)⌉ ; t_chg = Q·DOD/I_ch
```

### 4.5 稳定性与制动

```
H_cg,act = Σ(m_i·h_i) / M
a_crit,X = g·(bx/2) / H_cg,act   K_st,X = a_crit,X / a_X
a_crit,Y = g·(by/2) / H_cg,act   K_st,Y = a_crit,Y / a_Y
K_st     = min(K_st,X, K_st,Y) ≥ 1.5
```

### 4.6 结构与尺寸链

```
q     = M·g·K_d / (n_b·L)
M_max = q·L² / 8
I     = (B·H³ − b·h³)/12 ; W_x = 2I/H
σ     = M_max / W_x ≤ σ_s / n
δ     = 5qL⁴ / (384·E·I) ≤ L/n_defl
c_v    = h_layer − (t_panel + h_cargo + h_lift + Δh)
c_side = (w_slot − W) / 2        （无货叉，用车身宽）
```

## 5. 校核清单（16 项）

| 校核 | 判定 |
|---|---|
| 电机功率 | 单机需求 ≤ 样本额定功率 |
| 附着力 | μ·M·g·(k/4) ≥ ΣF |
| 轮压（塑料搁板） | p_max ≤ min(轮材许用, 塑料搁板许用) |
| 支柱载荷 | N_post ≤ 单柱许用，且 σ_post ≤ p_shelf |
| 主梁挠度 | δ ≤ L/500 |
| 运行稳定 | K_st ≥ 1.5 |
| 顶升行程 | h ≥ Δh + 余量 |
| 凸轮压力角 | α ≤ 许用压力角 |
| 凸轮转矩 | T_cam ≤ 凸轮额定转矩 |
| 电池容量 | Q ≥ Q_req |
| 续航覆盖班次 | 续航 h ≥ 每日工时 |
| 主梁强度 | σ ≤ σ_s / 1.5 |
| 制动距离 | s_b ≤ 允许值 |
| 换向离地间隙 | Δh ≥ 3 mm |
| 尺寸链间隙 | min(c_v, c_side) ≥ c_side 要求 |
| 偏心轮压放大 | N_max ≤ 1.25N |

每项输出通过 / 警告 / 不通过 + 数值对比 + 一句话建议；不通过与警告项还会额外显示：
**影响（后果）** —— 该指标不达标在实机上会发生什么（如搁板压陷、启动打滑、凸轮自锁、中途断电等）；**建议** —— 可执行的改进方向。余量 <10% 的通过项自动降级为"警告"。CSV 与打印计算书也会带上这两列。

## 9. 已知简化与假设

1. **轮压用赫兹线接触**，塑料搁板视为刚体平板，未考虑搁板局部塌陷与长期蠕变；峰值轮压按 `4p_avg/π` 估算。
2. **塑料支柱只做轴向压应力与许用载荷校核**，未做偏心弯折、连接节点与老化折减。
3. **主梁按简支梁均布载荷**，未做扭矩、剪切、焊缝与疲劳校核；截面按等壁厚方管。
4. **凸轮转矩按功率法**（`F_cam·v/(ω·η)`）估算，未按凸轮实际位移曲线做接触应力与弹簧回位校核；`n_cam` 与 `t_lift` 的运动学一致性需人工确认。
5. **顶升功率按平均速度**计算，未计冲击峰值、导向摩擦与热平衡。
6. **电池能耗**默认按匀速近似，可切换为加减速曲线积分；未考虑温度、老化与辅助功耗（PLC、传感器、通信）。
7. **状态切换时间**按 `max(t_lift, t_index) + 延时`，偏乐观；实际受定位精度、凸轮曲线与 PLC 节拍约束。
8. **稳定性**做静力临界加速度估算，未考虑轮子弹性、轨道不平顺、偏载动态转移与风载。
9. 每向 4 轮假设载荷均分，未做四角不平或三点支撑的重新分配（偏心工况按线性放大近似）。
