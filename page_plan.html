二、页面清单与功能详情

主页 核心入口

整机性能计算（主页）

/index.html
  • 🎯 三卡片布局：用户需求 + 环境参数 + 高级选项
  • ⚡ 点击"一键联动"自动调用齿轮/电机/电池模块
  • 📱 结果面板展示牵引力、总功率、扭矩、传动比、稳定性系数
  • 🔗 折叠区展示各子模块返回的详细结果
  • 📋 汇总 BOM 清单，可导出
  • 💡 独立使用：只填参数不点联动，也能出整机结果
联动调用： gear motor battery bearing cost
机械

⚙️ 齿轮传动选型

/modules/gear.html
  • 输入：功率 kW、输入/输出转速、使用系数、中心距约束
  • 支持直齿/斜齿/行星/蜗轮蜗杆四种类型
  • 输出：模数、齿数、螺旋角、材料、效率、重量、寿命
  • 📊 强度校核图 + 传动比分配可视化
  • 🛠️ 独立可用：手动填参数直接出结果
被联动：主页、成本评估
机械

🔵 凸轮设计计算

/modules/cam.html
  • 输入：类型（盘形/移动/球面）、行程、转速、运动规律
  • 支持等速/修正正弦/修正梯形/摆线运动规律
  • 输出：基圆半径、压力角、速度/加速度/跃度
  • 📈 轮廓曲线 SVG 实时绘制
  • 📤 导出 DXF / 坐标点 CSV
  • 🛠️ 独立可用
被联动：主页、成本评估
电气

🔌 电机选型

/modules/motor.html
  • 输入：所需功率、扭矩、转速、电源电压、负载持续率
  • 支持伺服/步进/无刷直流/异步感应四种
  • 输出：选定类型 + 推荐得分 + 规格参数
  • 📊 备选方案对比表（优缺点）
  • 🛠️ 独立可用
被联动：主页、齿轮、成本
机械

🔩 轴承与轴计算

/modules/bearing.html
  • 输入：载荷、转速、轴材料、工作温度
  • 支持深沟球/圆锥滚子/调心球等类型
  • 输出：轴承型号、L10 寿命、轴径、临界转速
  • 🛠️ 独立可用
被联动：主页、成本
机械

🔗 链/皮带传动

/modules/belt.html
  • 输入：功率、转速、中心距、环境
  • 支持同步带/V 带/滚子链
  • 输出：型号、节距、张紧力、效率
  • 🛠️ 独立可用
被联动：主页、成本
电气

🔋 电池容量计算

/modules/battery.html
  • 输入：功率消耗、续航时间、电压、充电方案
  • 支持磷酸铁锂/三元锂/铅酸对比
  • 输出：容量 Ah、重量、循环寿命、充电时间
  • 🛠️ 独立可用
被联动：主页、成本
经济

💰 成本评估

/modules/cost.html
  • 输入：年产量、加工费率、是否含装配/管理费
  • 接收各机械模块返回的零件清单
  • 输出：总成本 + 分项（材料/机加工/标准件/装配）
  • 📊 敏感性分析（材料±10%、产量±50%）
  • 💡 自动生成降本建议
  • 🛠️ 独立可用：手动输入零件清单
接收所有模块结果

四、技术方案（推荐路线）

层级方案理由
框架 纯 HTML + Tailwind CDN + Alpine.js / Vue CDN 零构建依赖，直接打开即可运行，每个模块独立 html 文件互不干扰
图表 ECharts（性能曲线、成本柱状图）+ SVG 手绘（凸轮轮廓） ECharts 功能强、CDN 可直接引；凸轮轮廓用原生 SVG 实时绘制无依赖
计算逻辑 原生 JS 封装为独立计算函数（math.js 做矩阵/方程可选） 机械公式纯函数实现，方便单元测试和模块间调用
联动机制 主页 fetch() 各模块计算函数 / 或直接 import 同一份 math.js 简单方案：计算函数放在 /js/calc/ 目录，主页和各模块 import
部署 GitHub Pages / traesite 静态部署 纯静态站点，GitHub Pages 免费托管，开发阶段用 traesite 快速预览
文件结构 /index.html + /modules/*.html + /js/calc/*.js + /data/*.json 每个 html 独立，计算逻辑复用，数据层与之前 feat/shared-params 对应
