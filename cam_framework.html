一、提示词整理（全部接收）

📦 第 1 批 · 基础功能（V1 核心）

B1参数输入：基圆直径/半径、凸轮宽度、从动件类型、滚子半径、旋向、分度分辨率
B1运动分段表：段名/转角/升程/运动规律；增删调序；校验角度和=360°
B1运动规律：等速、等加速等减速、余弦、正弦、3-4-5 多项式、停歇
B1从动件参数：直动偏置/摆动摆杆+支点位置
B1曲线生成表：s/v/a/j/α/轮廓坐标；滚动；导出 CSV
B1可视化：s/v/a/j 曲线 + 展开图/3D 线框；实时重绘
B1参数存取：JSON 文件保存/加载
B1校验提示：压力角超限、角度和≠360°、滚子自交；文字警告
B1技术形态：单文件 HTML、离线、零依赖
B1代码结构：数学模块独立，可被 SolidWorks 建模脚本调用

🚀 第 2 批 · 扩展功能 + 修改指令

B2浅灰主题：#f2f3f5 背景，禁深色；曲线/3D 重新配色
B2多语言切换：English / 日本語 / 中文；默认中文；localStorage；枚举本地化+JSON 英文
B23D 参数示意：每个参数标注几何位置；可在图上编辑/定位
B2STEP 导出：直接生成 STEP AP214，不接 SolidWorks
B2新增参数：滚子随动器长度（沟槽深度）、初始高度
B2分段累计角度：除第一段外每段显示累计转角
B2修正梯形：两端三次过渡+可设过渡区+滚子限制最小值
B2旋转速度：每段可设凸轮转速；正压力 + 输入扭矩曲线
B2传动效率：凸轮传动效率参数参与扭矩计算
B2运动方向：竖直/水平/倾斜；负载=质量+弹簧复位力
B2曲线压力角行：运动曲线新增一行显示压力角
B2警告+解决建议：所有警告后附建议文字
B2连续曲面：输出连续曲面，可直接加工
B2多滚子 3D：滚子数量、安装角度、旋转动画（正/反/步进/停止/进度条）
B2滚子连杆：滚子外连同直径同长度杆（朝向运动方向，不旋转）
B2分段负载质量：按运动分段分别设置

二、技术形态

方案结论理由
技术栈 单文件 HTML + 纯原生 JavaScript（纯 Canvas 2D 画所有图） 离线运行、零依赖、免安装、易分享；数学模块导出为独立 .js 可被后续 Python/SolidWorks 脚本 import 或翻译重写
3D 线框 纯 Canvas 2D + 手写 3D 投影 不引 Three.js，保持零依赖；线框显示完全够用
STEP 导出 手写 STEP AP214 文本生成器（ISO 10303-21） 圆柱凸轮曲面可用 B-样条曲面表达，STEP 文本格式可直接手写生成
运行方式 直接双击 index.html 浏览器打开 纯前端方案的常规启动方式，无需安装
